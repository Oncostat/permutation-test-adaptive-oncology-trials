# permutation-test-adaptive-oncology-trials

This repository GitHub includes the R codes to replicate the two simulation studies and the two clinical trial applications presented in the paper "Using permutation-based tests to evaluate an adaptive molecular treatment algorithm in randomized precision oncology trials" by Marelli et al. To run the clinical trial applications, two synthetic datasets generated from the SAFIR02-BREAST and the SAFIR02-LUNG datasets are provided.
